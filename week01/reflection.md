# Week 1 Reflection

This week I worked on the FinTrust data model and the first set of architecture decisions. The relationship between customers, accounts, and transactions made the SQL exercises easier to understand because each foreign key represented a real banking relationship. I also used the CPLG framework to justify `af-south-1` as the primary Region for the case study.

The main challenge was keeping the notes, queries, and diagrams connected. Organising the repository by week and linking each deliverable from the README made the work easier to follow and review.

I ran the full Week 1 schema and query set against MySQL 8.4.11. The scripts completed successfully, including the optional branches challenge, and the verification results are recorded in `evidence/mysql-verification.md`.
