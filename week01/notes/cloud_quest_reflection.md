# Week 1 Day 1 Cloud Quest Reflection

## AWS service used

I interacted with Amazon EC2. It provides resizable virtual servers that can run applications in the AWS Cloud.

## Challenge and resolution

The most confusing part was moving between the mission instructions and the AWS Console without losing track of the required step. I resolved it by reading one instruction at a time, completing it in the console, and returning to the mission before continuing.

## FinTrust connection

The AWS Console is where FinTrust's team can provision and manage cloud resources instead of purchasing and maintaining all infrastructure in the Johannesburg and Cape Town data centres. Services can be created when needed, monitored centrally, and deployed across Availability Zones for better resilience.

## Next learning goal

I want to understand how an architect chooses the correct AWS Region and Availability Zones while balancing data residency, latency, service availability, and cost.
